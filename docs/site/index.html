// why ocre

Everything a product needs.
Nothing to pay for.

Ocre follows Rails' conventions, rebuilt around what Cloudflare gives every account for free: one Worker, a SQLite database, a queue, object storage.

◆

Code you can read

Generators write ordinary Rust into your app: models with plain SQL, axum handlers, askama templates. No hidden runtime magic: open the file, change it.

$0

Built for the free plan

10 ms of CPU per request, 50 subrequests per invocation, 100,000 requests a day: every feature is designed and measured against those limits.

⌁

Made for AI agents

Every app has an AGENTS.md, every command speaks --json, and these docs come as /llms.txt. Agents write the code; you read it.

▦

Batteries included

Auth and OAuth, mail in and out, background jobs and crons, R2 uploads, WebSockets, i18n, webhooks, web push, a cache.

✓

Test what you ship

Unit tests natively, request tests against the real runtime (workerd), browser tests with Playwright: ocre test --e2e runs them all.

▲

One command to production

ocre deploy creates the database, queues, buckets and secrets it needs, migrates, then ships. No dashboard visit.

src/models/post.rs
/// A row of the `posts` table.
pub struct Post { pub id: i64, pub title: String, pub body: String, /* … */ }

pub async fn create(ctx: &Ctx, mut new: NewPost) -> Result<Post> {
    before_create(ctx, &mut new).await?;
    new.validate().finish()?;
    let post = ctx.db()?
        .first("INSERT INTO posts (title, body) VALUES (?1, ?2) RETURNING *", params![new.title, new.body])
        .await?
        .ok_or_else(|| Error::internal("no row returned"))?;
    after_create(ctx, &post).await?;
    Ok(post)
}
pub fn routes() -> Router<Ctx> {
    Router::new()
        .route("/posts", get(index).post(create))
        .route("/posts/{id}", get(show).post(update))
}

async fn show(State(ctx): State<Ctx>, flash: Flash, Path(id): Path<i64>) -> Result<Html<String>> {
    let post = post::find(&ctx, id).await?.or_404()?;
    render(&ShowView { flash, post })
}
// ocre g job SendWelcome user_id:integer
pub struct SendWelcome { pub user_id: i64 }

impl SendWelcome {
    pub async fn perform(self, ctx: &Ctx) -> Result<()> {
        let user = user::find(ctx, self.user_id).await?.or_404()?;
        ocre::mail::send(ctx, mailers::user::welcome(&user.email)?).await
    }
}

// In a handler: answered now, sent moments later.
SendWelcome { user_id: user.id }.perform_later(&ctx).await?;
#[test]
#[ignore = "request test: run with `ocre test --e2e`"]
fn shows_a_post() {
    let record = post();                      // a factory
    let title = record.title.clone();
    let id = record.insert();
    Client::new()
        .get(&format!("/posts/{id}"))
        .assert_status(200)
        .assert_contains(&title);
}
